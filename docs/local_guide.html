Verify on your laptop.

Clone the repository and run these commands with Python 3.11 or newer. The captured receipts are included.

PYTHONPATH=workbench/runner python3 -m humanscale run --scenario all --output /tmp/picchio_verify
python3 workbench/receipts/replay_workbench_receipts.py

Instant verification checks all four captured Apple M5 receipts, runs live host boundary probes and catches a SQLite total of 13 against the frozen target of 42. It then repairs the fixture and verifies 42. The receipt records captured inference results separately from fresh host checks. Repeat the command whenever you want.

macOS uses Seatbelt. Supported Linux kernels use Landlock and seccomp. Other hosts record the adapter availability and still run the captured receipt and live SQLite checks.

Run your own model

On macOS, install llama.cpp and point the runner at your own GGUF file below 3 GiB. Choose a new output directory for each inference run.

PYTHONPATH=workbench/runner python3 -m humanscale run \
  --model /absolute/path/to/your/model.gguf \
  --scenario all --output /tmp/picchio_inference

The agent, inference server and tools inherit one Seatbelt policy. The observer independently checks code, frozen original tests and SQLite. The instant route also works when the model argument is omitted or its file does not exist.
