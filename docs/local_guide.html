Run the checks on your Mac.

Use the MIT runner included in this project. Install llama.cpp and choose a local GGUF file below 3 GiB. The reference recording uses the pinned Qwen model in workbench/model.json.

python3 workbench/fetch_model.py
PYTHONPATH=workbench/runner python3 -m humanscale run \
  --model workbench/models/qwen2.5-coder-1.5b-instruct-q4_k_m.gguf \
  --scenario all --output workbench/receipts/my_run

The runner starts the agent, inference server and tools inside one Seatbelt policy. The observer saves raw evidence and checks the code, original tests and SQLite row independently. Give each run a new output directory.

Recompute the saved results

python3 workbench/receipts/replay_workbench_receipts.py workbench/receipts/my_run

In the workbench, use Open receipt and choose a receipt JSON to review it. Files are read inside the browser. The page does not scan your computer or start a model by itself.

Use an installed command

pip install ./workbench/runner
humanscale detect

Python 3.11 or newer is required. Memory enforcement uses observed resident memory and can overshoot between samples. macOS GPU activity samples describe the whole GPU. Missing evidence is shown as UNKNOWN.
